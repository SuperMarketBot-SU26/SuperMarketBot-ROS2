# smb_nodes

Higher-level ROS2 nodes for SuperMarketBot.

## Planned nodes

- `safety_watchdog` — emergency stop on bumper, low battery, or stalled wheel
- `auto_dock` — return-to-dock behavior using fiducial marker
- `state_machine` — top-level FSM (idle → nav → pause → dock)

## Status

Skeleton only. Nodes are added in Phase 3+ after the firmware protocol is stable.
