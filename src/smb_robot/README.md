# smb_robot

Robot description package for SuperMarketBot.

## Contents

- `urdf/` — URDF/Xacro files describing the physical robot (chassis + wheels + lidar mount)
- `meshes/` — STL/DAE meshes for visualization
- `launch/` — launch helper for `robot_state_publisher`

## Status

Skeleton only. URDF is created in Phase 3 once we have the physical dimensions.
